## 已实现的实验模块

`scripts/research/recording-api.cjs`可由Node合成测试加载，也可临时在已初始化的官方页面内执行。注入学校官方请求客户端；模块自身不读取认证存储、请求头或令牌，也不提供任意URL请求。

- 仅开放当前学期课程列表、已取得学校课程ID的指定录播页，以及取消。
- 固定两个只读业务端点，固定每页10条；课程原始分组参数只保留在页面内部，返回现有业务模型字段。
- 校验官方HTTPS主机/路径、学期、重复课程ID、分页范围、总数、条数、日期、发布状态和重复录播ID；异常拒绝作为成功数据返回。
- 请求串行，有超时和取消代次；取消/超时/离开可信路径后的迟到响应不能写入新课程上下文。错误仅返回类别，不返回原始错误/请求配置。
- 当前实现是研究适配器，没有加入Flutter资产、默认导入或持久化路径。跨来源完整收集/原子保存继续由既有应用层负责，不能把逐页模块当作完整导入器。
