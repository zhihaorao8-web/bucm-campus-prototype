## 第一阶段实现与用户反馈

- 仅今日页采用24秒周期的连续柔光；背景用独立CustomPainter重绘，内容不随每帧重建。保持原其他页面静态光色及900ms切页淡变。
- 后台、非可见TickerMode、关闭极光、减少动画或高对比度停止持续ticker；减少动画保留静态光色，高对比度不绘制装饰。
- 今日顶栏初始近透明，前80逻辑像素滚动逐步提高雾化底色保护；关闭模糊或高对比度用不透明底。
- 焦点卡使用圆角裁剪后的局部背景模糊、细白高光边缘与轻阴影；保留原点击进入课程行为及原有按压反馈。本阶段不统一所有课程卡片。
- 用户看到首轮预览后指出浅色暗淡、通透不足。已改高亮白底和清透蓝/绿/杏柔光，渐变透明端保留原色，焦点卡白色填充降至26%–46%、浅色模糊10、减轻有色阴影；深色保留烟熏填充。此反馈属于第一阶段修订，不代表整体审核通过。
- 焦点时间44→38，卡片内边距24→22及组间距22→16，减少首屏占高，系统字号仍生效。
- 没有新增依赖、修改版本、构建发布或连接学校会话。
