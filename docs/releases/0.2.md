# 校园课表 0.2（预发布）

本次更新集中在课表阅读与设置体验：

- 工作日周视图自适应显示五列与早晚五个教学时段，默认字号下可总览整周；保留授课分段、冲突和课程详情。周末课程仍保留在数据及日视图中。
- 相邻课程卡片颜色不同；修复日视图星期按钮文字空白，适配窄屏与大字号。
- 设置首页保留登录与隐私，新增外观设置与项目信息。外观偏好保存在本机，支持主题、适用系统Monet/强调色、Material 3风格/对比度、模糊、悬浮/玻璃底栏、适用返回/切页手势及界面缩放。
- 项目信息展示原生应用名称/版本、图标、Muzhi的GitHub头像与名称，点击可打开开发者主页；仓库支持打开和复制。

## 安装包

- Android包名`cn.bucm.campus_schedule`，Android 8及以上。
- 显示版本`0.2`，内部版本号8，pubspec为`0.2.0+8`。
- 附件`campus-schedule-0.2-android-release.apk`为启用R8的release构建，`SHA256SUMS.txt`提供SHA-256校验。
- 沿用本机开发签名，可覆盖同签名Flutter预览包，仍未建立生产签名流程。旧Java原型包名不同，不自动迁移数据。

## 验证边界

合成测试验证课程展示、布局、设置持久化、实际主题与交互、原生信息接口替身及公开头像解码；发布检查的精确结果、源码SHA和CI记录见`docs/STATUS.md`。

学校官方认证、导航、新窗口导出及完整学期准确性仍需在本人授权会话下分别验证；本次不使用真实课程或会话作为CI数据，不将已有本机课程显示等同于链路重新通过。系统Monet及预测返回能力依赖Android版本和设备设置。

此为非官方研究预发布，不含提醒、社区、直播、图书馆或其他平台交付。不覆盖既有发布标签或附件。
