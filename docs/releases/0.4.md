# 校园课表 0.4 · 预发布

2026-11-20，Android 版本 0.4，versionCode 13，Flutter pubspec 0.4.0+13。

## 本次变化

- **图书馆座位预约原生全链路（阶段 1–6）**：接入学校官方预约页面登录与 WebView 会话复用（延续正常 TLS 与域名校验，不记录密码、验证码或 Cookie）；实现同源只读查询（`/ic-web/seatMenu`、座位余位、本人预约）以及明确二次确认后的单次原生预约（`POST /ic-web/reserve`）与原生取消（含防连点、余位复核与结果不明先查单不重发）。
- **四项悬浮底栏与图书馆前端重设计（阶段 7A–7C）**：悬浮玻璃胶囊底栏升级为四项（`今日 · 课表 · 图书馆 · 设置`），`图书馆` 惰性加载并与合成示例严格隔离；离线增补 6 个 IconMCP 图标至 49 个；落地交互平面选座图与紧凑 4 列网格双视图、`08:30–22:00` 时间轴与选区/时段 `QuietSheet`、悬浮选中操作胶囊、柔光确认/取消抽屉及“我的预约”焦点票卡。
- **三级渐进空间选座与体验修正（阶段 8A–8C）**：构建 `楼层列表（L1）→ 楼层整体平面示意图（L2）→ 区域座位图（L3）` 渐进选座，专绘 2F 独立北区与 3–5 层连续 L 形 `西C` / `中庭` / `↑ 北` / 非选座区域示意图；L3 平面图采用 `1.72:1` 等比投影修正 `西A区`/`南区` 与缩放显号、控制区三组分区重排及顶栏索引条垂直居中，支持 `PopScope` 与定位胶囊逐级退回。
- **图书馆顶栏高度与 B1 艺术标题统一（阶段 8D）**：扩展自研 9° 前倾 B1 Macintosh Skeletal Filled 字形与 20 笔有向中心笔顺至 `图 / 书 / 馆`（7 字全集），使 `图书馆` 与 `今日` / `课表` 共用展开顶栏高度与 `1350ms` 描边入场动效、折叠回退居中系统标题（`设置` 保持纯系统字体）。
- **工程治理与核验基线**：纳入 A–F 长期项目管理与分层测试（`scripts/check.py` / `scripts/ci_plan.py`）及双包顺序构建核验工具（`scripts/build_flutter_previews.ps1` / `scripts/verify_apks.py`，兼容 Build Tools 37 单一 V2 签名输出）。

## 选择安装包

普通使用下载 `campus-schedule-0.4-android-release.apk`；排查问题下载 `campus-schedule-0.4-android-debug.apk`。两种模式均显式启用 `CAMPUS_DIRECT_CATALOG=true`。仅 debug 启用测试诊断（`CAMPUS_TEST_DIAGNOSTICS=true`），可在“设置 → 项目信息 → 测试诊断”查看/复制/清空；release 不显示入口、不采集诊断，即使传入诊断开关也受发布模式硬关闭。

包名 `cn.bucm.campus_schedule`，沿用既有 Flutter 预览版本机兼容开发签名（非正式生产签名，不提交密钥）；同签名旧 Flutter 预览版可直接覆盖升级保留数据，与早期 Java 原型包名不同。详细变更历史见 [CHANGELOG](../../CHANGELOG.md)。
