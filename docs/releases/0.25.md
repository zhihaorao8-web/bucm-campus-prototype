# 校园课表 0.25（预发布）

本次更新加入轻新课堂录播，与现有课表结合：

- 点击今日、周/日课表课程进入录播二级页，按学期及名称匹配学校课程，同名歧义保留本人确认。
- 设置“轻新课堂 → 统一导入录播”和课表右上角录播图标提供同一入口。完整分页逐门导入并保存本机目录，多次排课复用同一门学校课程；导入后直接查看和翻页，重启保留，支持单课刷新与中断保留。
- 内置播放器默认PPT主画面、教师小窗，支持学生画面切换、交换主小画面、独立关闭/恢复小窗、暂停、进度、倍速与全屏。
- 新增短时页面缓存及上下文复用，减少重复进入流程，保留列表分页与位置。修复学校媒体节点映射导致的缓存/刷新后播放失败。
- 自动选择学校直连或官方WebVPN入口；教务新窗口全屏显示并支持缩小、适应宽度和放大，右侧账户/退出入口可访问。

## 安装包

- Android 8及以上，包名`cn.bucm.campus_schedule`。
- 显示版本`0.25`，内部版本号9，pubspec为`0.25.0+9`。
- 附件`campus-schedule-0.25-android-release.apk`为启用R8的release构建；`SHA256SUMS.txt`提供SHA-256校验。
- 沿用本机开发签名，可覆盖同签名Flutter预览包。仍未建立生产签名流程，不能保证覆盖其他机器不同签名的安装包。

## 验证与限制

学校登录、扫码或账号密码认证仍由本人在官方页面完成。有效会话可复用；不新增密码文件、凭据导出、开发者代理或后台保活，不缓存视频及媒体地址。

已完成的本机合成检查与授权学校样本验证分别记录在`docs/STATUS.md`；发布需独立核对压缩后的解析、正常包名、版本、签名、精确源码CI和附件摘要，不能用旧debug通过替代。

直播入口仅占位，当前没有开放实际直播；学校观看记录尚未接入。7天免登录仍待自然跨天验证。完整学期准确性、所有学校媒体源质量、人工音频听感、长时同步和开启水印配置均不作全面通过声明。

本项目是非官方研究预发布，保留既有版本标签和附件，不包含提醒、社区、图书馆或其他平台交付。
