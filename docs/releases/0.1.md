# 校园课表 0.1（预发布）

Flutter Android第一版：今日/下一节课、离线周/日课表、学期与教学周切换、分段授课、冲突课程、课程详情，以及MIUIX页面和悬浮玻璃底栏。

本人在学校官方页面登录，优先从官方Excel导入课表，DOM作为备用。应用不保存密码，不上传个人课表；合成示例只在内存展示。

## 安装包

- Android包名：`cn.bucm.campus_schedule`，Android 8及以上。
- Android显示版本：`0.1`；内部版本号：7。Flutter pubspec使用等价SemVer `0.1.0+7`。
- 附件`campus-schedule-0.1-android-release.apk`为release模式构建，`SHA256SUMS.txt`用于校验下载文件。
- 当前沿用本机开发签名，便于同签名预览覆盖更新，尚未建立生产签名流程。旧Java原型与新Flutter应用包名不同，不自动迁移其数据或会话。

## 验证范围

本地静态分析、13项Flutter合成测试、Java/DOM/XLS合成检查已有通过记录；AVD合成方法通道与MIUIX页面切换已有通过记录。发布前另检查release包的签名、版本、ZIP完整性与许可资产。远程构建证据见本次源提交的GitHub Actions。

release构建保留R8压缩，使用精确规则处理HSSF反射和未使用的桌面/OSGi依赖；独立空白Android 16 AVD上的压缩后二进制XLS合成测试通过（1项，0失败），覆盖教师、周次及分段时间，不使用学校会话或真实课表。测试目标保留运行器共享Kotlin/Tracing类，正式附件不包含此测试配置。
