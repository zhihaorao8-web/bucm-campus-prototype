# 校园课表 0.3 · 预发布

2026-11-14，Android 版本 0.3，versionCode 12，Flutter pubspec 0.3.0+12。

## 本次变化

- **柔光亚克力全套界面与轻盈动效**：今日页采用 10 秒双层轻盈灵动柔光背景、半透明 `AcrylicSurface` 焦点卡片、授课分段进度条与连接时间轴；课表与设置页采用静态全幅弥散光场，自动支持系统高对比度、应用对比度与关闭模糊/玻璃退回实色。
- **连续导航、悬浮底栏与课表细节**：一级页面采用统一 260ms 分页转场与自研悬浮玻璃胶囊底栏，独立保留折叠顶栏与滚动状态，支持可选跟手横滑；日视图星期栏采用单层实时模糊；周视图支持全列宽层叠冲突、底部 `QuietSheet` 冲突详情抽屉、本周高亮与可选周末七列；点击播放按钮支持 280ms 圆形扩张过渡。
- **B1 艺术标题与今日语录**：「今日」「课表」左上角展开大标题改用自研 9° 前倾 B1 方案 Macintosh Skeletal Filled 圆管矢量字形与 1350ms 苹果开机风格逐笔描边入场动效（移除旧版 5.16 MB 第三方字体文件）；「今日」页顶端新增随机语录卡片（默认内置 24 条离线格言，可选在外观设置启用“在线一言”）。
- **「课程课堂」页重设计**：采用实时模糊“录播 / 直播”滑动玻璃开关、单张 `QuietCard` 连接与“刷新录播 / 重新匹配同名课程”维护中心，以及分层优化的“回放来源”、本次课日期徽章、已发布状态胶囊、响应式分页条与同名候选课程列表。
- **播放器与学校接入修复**：横竖屏拖动进度条时在视频画面中央实时显示目标时间 / 总时长；补入 `qxkt1` HTTPS `:8880` 直连媒体节点；学校页面提交后提前识别可用目录/分页；课程名称匹配兼容全角/半角括号。

## 选择安装包

普通使用下载 `campus-schedule-0.3-android-release.apk`；排查问题下载 `campus-schedule-0.3-android-debug.apk`。两种模式均显式启用 `CAMPUS_DIRECT_CATALOG=true`。仅 debug 启用测试诊断（`CAMPUS_TEST_DIAGNOSTICS=true`），可在“设置 → 项目信息 → 测试诊断”查看/复制/清空；release 不显示入口、不采集诊断，即使传入诊断开关也受发布模式硬关闭。

包名 `cn.bucm.campus_schedule`，沿用既有 Flutter 预览版本机兼容开发签名（非正式生产签名，不提交密钥）；同签名旧 Flutter 预览版可直接覆盖升级保留数据，与早期 Java 原型包名不同。仓库访问权限保持原设置。
