## 本次更新

- 修复 `v0.41`（`0baba2c`）在真机（Xiaomi HyperOS / Impeller Vulkan）点击「今日」焦点卡或课程卡片进入详情页、返回及「周 / 日」切换期间出现的全屏平铺圆角黑块渲染异常：
  - 在 `mobile/lib/ui/visual_policy.dart` 新增共享转场与局部渐变暂停底座（`BackdropTransitionBuilder`、`BackdropSuspensionScope`、`BackdropSuspensionAnimation`），覆盖 `CourseCardHero` 返回飞行、`QuietSliverAppBar`、`QuietSheet`、主/设置 `MiuixTopAppBar`、`ScheduleModeTransition` 及选座胶囊进出过渡。
  - 重构 `GlassNavigation` 与 `AcrylicSurface`（及 `ClassroomSectionSwitch`）消除嵌套 `BackdropFilter` 与重复 `ClipRRect`，并为 `LiquidGlassSurface` 等滤镜补充 `TileMode.clamp`。
