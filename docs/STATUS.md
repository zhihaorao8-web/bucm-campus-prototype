# 进度与验证边界

最后更新：2026-11-08。

## 当前目标

只验证“官方页面认证 → WebVPN / 本科教务会话 → 本机提取本人课表数据”的可行性。暂不继续开发缓存、展示、提醒等产品功能。源码保留早期试验，不表示这些功能都已完成。

## 已验证

- 用户本人在学校官方页面完成认证，Android 客户端通过 WebVPN 进入本科教务系统。
- 后续重开和覆盖更新后，既有学校会话曾可继续使用；未证明可以无限续期。
- 当前周课表通过 DOM 读取识别出18个非空候选单元格。
- “个人课表信息 → 学期理论课表 → 周次全部”页面识别出25个非空候选单元格。
- 从一个真实单元格读取到三段不同周次的排课文本，在本机验证脚本中完成样本结构化并与原网页核对。
- 可读字段包括课程名、教师、星期、周次表达式、节次和地点。
- 数据读取逻辑在手机 WebView 内执行，不依赖自建服务器或 root。

18与25都是单元格数，不是独立课程门数。真实样本、账户、截图、会话和设备标识不进入仓库；`examples/`仅放明确标记的合成数据。

## 尚未通过或未验证

- 全学期所有独立课程的拆分、去重及逐条核验。
- 内置通用解析器对`9-17(周)[01-02-03节]`及分隔线课程块的完整适配。本次真实样本的结构化由本机验证脚本完成，不能视为内置解析器全部通过。
- 节次到HH:mm的官方时间映射、实验见习、临时调停课。
- 离开 WebView 后，独立 HTTP 客户端复用会话并直接调用 JSON 接口。
- 第三方应用正式注册到学校 CAS / OAuth / OIDC，以及获取身份属性的授权。
- 成绩、校园卡、电量、图书馆和研究生系统。
- 后台定时通知。即时通知曾送达，但定时接收器未取得同等证据；相关试验已停止。
- AVD环境的学校认证与数据提取。

## 下一步

1. 在AVD复现已验证的页面读取路径，并记录WebView版本与失败分支。
2. 为学校实际课程块格式创建合成固定样本，分别验证周次、节次、同名课程拆分和去重。
3. 保留人工核对，直到完整学期逐条核验完成。
4. 如需其他校园数据，为每个系统单独验证认证、会话和数据权限。
