# 2026-11-13 前端设计优化

用户要求根据[所附设计提示词](requirements/UI_DESIGN_PROMPT_20261113.md)优化当前应用，并明确确认冲突课程改为层叠卡片。

## 适配范围

提示词作为设计参考；实现继续使用现有Flutter、MIUIX、Riverpod与离线IconMCP资源。采用暖纸色、莫兰迪色、色条/柔和底卡片、按页面变化的极光、纸纹、等宽数字、今日焦点/时间轴、周次控制、冲突抽屉和玻璃底栏。

- 持续装饰动画改为有界的切换与状态反馈；减少动画直接切换，高对比度不绘制极光/纹理。避免页面常驻动画影响观看或耗电。
- 保留相邻课程错色，不按学科猜分类；不修改课程内容、作息、导入、认证或录播路径。
- 周视图默认五列；按提示词增加可选周末列，七天在日视图始终可看。
- 冲突按实际授课分段判定，层叠不丢数据；点击展示全部冲突条目及准确时间，可选择本次页面优先显示。刷新/换学期后不把显示偏好混入学校数据。
- 保留进入课程录播页的路径，抽屉提供清晰的查看课程入口。日视图不新增无实现的提醒/备注开关；提醒与备注仍需独立确认。
- 不迁移为单HTML、不限制原生页面为430宽、不增加在线字体或重型依赖，不触及播放器沉浸布局。

## 分项与验收

1. 视觉基础与外观设置：旧设置文件兼容、实际开关、浅深色/高对比度/减少动画，现有导航和课程入口可用。
2. 今日：按真实分段显示正在上课/下一节、剩余时间与进度；连接时间轴区分已结束/进行中/待开始，休息只表示真实空档。合成时间边界和小屏大字检查。
3. 课表：层叠与全部冲突抽屉、优先切换、周次横滑与本周、日期高亮、可选周末。覆盖链式冲突/相接不冲突/分段准确，布局可达性及回归。
4. 设置：按原提示词补充教务同步卡片，展示当前学期已知更新时间，按钮进入原官方导入流程；不新增后台同步或静默登录，不伪造同步动效/时间。

每项检查和文档更新后独立提交推送当前功能分支。最终顺序构建干净提交debug包，核验来源、签名与资源；合成预览与手机真实反馈分别记录。不自动合入main、变更0.27版本或替换已发布附件。
