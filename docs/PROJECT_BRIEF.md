## 产品目标与第一版范围

2026-11-10轻新课堂补充确认：继续按服务可达性选择直连/WebVPN，保留手动切换，不读取Wi-Fi名称，不申请位置权限。自动选择只决定官方页面入口，不自动输入密码或搬运会话；页面与媒体可达性分开验证。

长期目标是把分散在学校多个网页中的校园生活功能聚合到一个应用，不设开发者独立后端。客户端在本机完成允许的数据读取、解析和缓存。

**第一版只交付Flutter Android课表应用：**

1. 在可见的学校官方页面完成认证；有效会话可以继续使用，失效后由学生本人重新登录，应用不保存密码。
2. 优先读取学校官方Excel，DOM作为备用；完成整批解析、校验、完全重复去重和本机保存，同学期重复导入更新该学期，保留其他学期数据。失败保留原有课表。
3. 支持教学周、单双周、节次列表/范围、连堂与分段授课；同一时段的课程并排保留，不用覆盖隐藏冲突。
4. 提供周/日视图、学期/周次切换、教师/地点/周次/授课时间/来源详情，以及今日课程和下一节课。
5. 本机课表离线可用，重启后保留；提供用户主动刷新入口，以及明确的导入、失败和空状态。
6. 使用MIUIX界面、Apple风格悬浮底栏与顶/底栏模糊；支持深色模式、大字、可达触控区域和系统安全间距。

用户于2026-11-10补充周视图要求：参照所给图片改成紧凑时段网格，周一至周五同屏、默认字号尽量完整显示早晚课程，不再依赖左右滑动；周末按用户后续要求不显示在周视图，保留原始数据、实际授课分段和冲突，不照抄图片中的课程信息。大字/短屏保留纵向展开和日视图完整阅读入口。详细布局见`DESIGN.md`。

同日补充配色规则：相邻课程模块颜色不同，覆盖周表的上下/左右邻接、冲突并排和同名分段；今日/日视图相邻列表项也错色。颜色由展示位置分配，不再由课程名固定决定。

同日新增设置重构：只保留原“登录与隐私”模块，新增外观设置与页面底部的项目信息入口；项目信息以图标居中、名称/版本、开发者与仓库分组展示。外观参照用户图片实现可用主题/颜色/底栏/手势/缩放，保存到本机独立设置文件。用户明确跳过KernelSU专属的角标数量和模块描述行数；SPEC_2025未由现有Flutter配色接口提供，按实际Material 3风格和对比度实现，不标注虚假支持。版本从原生包信息读取，开发者/仓库使用已确认GitHub项目资料。

## 当前技术与实现约束

- Flutter + Riverpod；应用、数据、领域、平台适配和UI分层，具体目录与构建步骤见`FLUTTER.md`。
- 根Java原型保留作为验证基线；学校二进制XLS暂复用HSSF与已有作息、去重规则，方法通道不返回Cookie或密码。
- 依赖使用已验证兼容版本和锁文件；不为追求“最新”破坏现有构建。界面采用锁定的`flutter_miuix`组件，不引入未使用的播放器或座位模型。
- 课程按北京时间；白天保留课间授课分段；晚间任意09至12节组合统一18:00–20:25，第12节不延长。学期起点、周末线上与地点编码解释均保留用户来源。详见`COURSE_TIME_RULES.md`。
- “无课表课程”没有可排日历的时间，先提示未处理区域，不猜测星期、节次或时间。
- 合成预览必须明确标记、只在内存展示，不混入本人课表。真实课程和学校会话不进入Git、测试或CI。
