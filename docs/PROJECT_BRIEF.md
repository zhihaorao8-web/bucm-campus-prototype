- 本人在可见的学校官方页面扫码或输入凭据；App可复用有效WebView会话，不额外记录密码、验证码、Cookie或令牌。计划中的密码加密保存/自动重登未获本轮实施授权。

- 正常TLS、逐跳域名、明确媒体节点/路径校验继续生效，不全局放开HTTP、端口或证书，不引入开发者代理。不读取Wi-Fi名称或申请位置权限；按服务可达性选直连/WebVPN并保留手动选择。
- 本地仅保存必要课表、录播目录及经确认实施的观看进度元数据；不下载视频或长期保存媒体地址。真实课程、截图、HAR、会话、设备标识与密钥不进入Git/CI，自动检查使用合成数据。
- 退出学校会话清理课堂目录/工作上下文，保留离线课表；清空课表同时清理本模块的有效备份与损坏副本。不能将上一账号目录/进度归给新账号。

## 课表规则

- 优先读取官方二进制XLS，DOM备用；整批解析、结构/时间校验、完全重复去重后保存。同学期更新，保留其他学期；失败保留既有数据。导入无需逐门确认，维护验收仍须独立核对完整学期。
- 支持单双周、周次/节次列表及范围、分段授课和冲突并排。课程按北京时间判断；白天保留课间分段，09至12节任意晚间组合统一18:00–20:25，第12节不延长。具体作息、学期起点和地点编码来源见[时间规则](COURSE_TIME_RULES.md)。
- “无课表课程”没有可排日历的时间，明确提示未排入，不猜星期/节次；独立列表需另行确认。
- 今日/下一节、周/日、学期/周次切换、完整详情及离线重启保留继续生效。周表工作日五列同屏，周末数据仍在日/今日可看；配色按相邻位置错色，不改变课程身份。
- 损坏缓存恢复页已确认突出重新导入，备份恢复放入更多操作；保留原文件，校验后替换。更新时间按学期，无法归属的旧全局时间显示未知，不替历史补造时间。

## 轻新课堂规则

- 2026-11-13用户新增播放器左右滑动调进度与配合的横屏全屏，明确竖屏和横屏均支持：主画面向右前进、向左后退，预览后松手跳转；小窗继续用于拖动/缩放。随后要求横屏进度条可隐藏、背景透明，并取消多行功能面板，将画面切换等集中到右上角一个可隐藏按钮；具体选择界面最终指定为侧边抽屉，屏占不超过50%。按[调研与分项](research/PLAYER_SWIPE_FULLSCREEN.md)推进，沿用当次权限和原生播放组。
- 从课表/今日进入课程二级页；默认录播，直播保持明确未开放入口，不请求实际直播。设置与课表页均提供统一导入当前所选学期课程的入口。
- 同学期、只整理首尾/连续空白后的精确名称匹配所有学校课程条目并汇总。教师、班级、课程序号仅作来源标签，不筛掉其他同名教师，不模糊包含、不跨学期、不要求从同名条目只选一门。
- 每个来源完整分页取齐后，整组原子保存；任一来源失败保留旧目录。本轮完整来源可复用，未完成来源不能作为已完成集合展示。播放按学校课程ID＋录播ID找回原来源/分页并核对当次权限。
- 已导入目录本机持久保存，可离线翻页，播放才按需连接。工作页面最多保留最近两门、从实际取得起5分钟；过期/失效/清除登录/课表重导入按既有规则清理，不缓存视频或永久媒体URL。
- 用户已确认课程摘要/可展开详情、顶部本次课回放、其他日期倒序和教师来源，保留录播/直播页签。当天多条均可查看，无对应不播放相邻日期；日期重排不改变原始播放身份。
- 用户已确认统一导入任务面板采用同一列表按状态分组，区分未匹配和失败，支持只重试失败及查看已完成课程；不自动扩展为后台任务或跨进程续传。
- 内置播放器取代旧官方播放器方案：默认PPT主画面、教师小窗，学生画面可切换。小窗关闭/恢复独立于画面菜单，同屏一路音频，统一控制与返回停止。来源见[选型](research/QINGXIN_NATIVE_PLAYER.md)。
- 用户已确认小窗单指拖动/双指缩放、轻点交换及本次布局保留；本机续播先选继续或从头，有效进度不足10秒/距结尾不足30秒时从头。仅保存学期/学校课程/录播标识、位置、时长和更新时间，退出会话清除；当次权限检查仍在前，不等于学校观看记录。
- 水印按学校官方配置；本机进度不等于学校观看记录。观看记录须协议核实并另行确认，不隐藏官方播放器补报。后续小窗/续播等改进的具体设计按计划确认。
