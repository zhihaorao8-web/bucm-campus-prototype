- 计划编写基线为当前分支 `codex/auto-course-import`、源码 `f194b3e`；已发布 `v0.25` 仍固定于 `652e45b`。后续开发开始前重新核对实际源码和工作区，不把本文当作永久版本清单。

## 持续生效的边界

1. Android优先，沿用MIUIX、今日/课表/设置三项一级导航、工作日紧凑周表及日视图七天入口。浅深色、小屏、大字、触控与无障碍要求继续生效。
2. 课程回放继续按同学期、仅整理空白后的精确名称合并所有学校条目；教师、班级不是筛选条件。按学校课程ID＋录播ID区分记录，不能仅按日期、标题或录播ID去重。
3. 学校认证由本人在可见官方页面完成，有效WebView会话可复用；不额外保存密码、验证码、Cookie或令牌，不修改TLS校验、逐跳域名及媒体路径边界，不放开明文访问或引入开发者代理。
4. 密码保存和自动重登仍为另一项待确认的专项，不由本计划启动；以后若另行确认自动重登，触发范围仍受用户此前指定的打开App、刷新课表、观看录播约束，不据此增加定时保活或后台登录。
5. 只保存必要课表、目录与拟议的本机播放进度元数据，不缓存视频或长期保存媒体地址。清除学校会话继续清理课堂目录/上下文，保留离线课表；新进度数据另按下文清理。
6. 直播继续仅显示未开放入口；离线下载、后台播放、提醒、图书馆、社区及其他平台交付均不进入本计划。真实直播须学校开放后单独确认与验收。
7. 合成数据用于自动检查；真实页面与媒体只在本人授权的会话中验证，不提交课程、截图、HAR、会话存储、设备标识或密钥。

## 阶段S1：连接故障恢复与状态提示

**工作内容（R1、U6基础）**

- 明确等待本人认证、门户导航、平台加载、数据读取、学校服务不可达、权限失效及媒体失败的状态、可用操作和重试边界。
- 增加对WebVPN返回的上游错误HTML的识别，不能只依赖WebView原生加载错误；先识别已知错误，再判断认证，避免把错误页误当作等待登录。
- 核实官方HTTPS认证回退和入口恢复链路；仅在来源/路径验证通过、用户已授权的连接流程内执行有界恢复，禁止无限跳转或盲目替换任意HTTP地址。
- 保留原生目录与当前目标，需认证时呈现可见官方页面；认证成功后恢复课程、所选日期、导入任务或列表位置。官方页仍可由用户返回/关闭。
- 状态提示同时表达目录新鲜度和连接结果，例如“本地目录 · 更新失败”，避免用一个“加载中”覆盖全部阶段。

**验收与交付**

- 合成覆盖真实错误类型的去隐私页面样式、正常认证、学校返回错误文档、超时、取消、前后台及重复跳转；不把真实页面文件放入测试。
- WebVPN错误页不再提示等待认证；失败时旧课表/目录可见，并有符合故障原因的重试或返回动作。
- 在本人授权会话中分别记录官方页展示、认证完成、平台到达、目录读取的结果。学校仍不可达时只验收正确错误处理，不宣称恢复登录成功。

## 阶段S2：离线数据保护、更新时间与准确性

**工作内容（R2、R3、R4准备）**

- 缓存读取失败时保留原文件，并保持恢复页面、设置及重新导入路径可达；设计上一份有效备份与用户主动恢复操作，避免反复读取同一损坏文件形成死路。
- 校验备份后才能恢复；重新导入成功并完成校验后再替换现用数据。权限、磁盘不足、未知schema、超限或解析失败不自动清空旧数据。
- 将课表导入时间和摘要按学期管理，兼容现有单时间字段，无法确定旧时间所属学期时显示未知，不伪造历史。
- 录播按完整同名课程集合显示最后成功更新时间；刷新失败保留旧时间与旧目录，并显示失败结果。
- 提供本次课表新增、调整、移除的简短摘要；比较规则保留不同周次、分段、教师与地点，避免仅凭同名就判定完全相同。新旧首次无法可靠对应时明确说明。
- 建立完整学期核验清单：官方XLS范围、所有字段、星期/周次/节次、实际授课分段、地点缺失、完全重复去重、跨学期保留与重复导入不累加。
- “无课表课程”继续显示未排入日历的边界；独立列表若需要，实施前另行确认，不能猜测授课时间。

**验收与交付**

- 合成覆盖损坏/过大/未知格式、备份有效/无效、保存失败、旧格式迁移、多学期更新时间隔离与差异摘要。
- 原子保存继续有效；恢复失败保留原数据，正常导入和离线读取不退化。
- 完整学期逐项核对只记录计数、差异类别和结论；区别“读取成功、结构化成功、保存成功、独立全量准确性通过”。真实核验在S5汇总结论。

## 阶段S3：课程、录播列表与统一导入UI

### U1、U2：课程页与按日期整理的录播

- 顶部保留课程名、学期、教师来源摘要；地点、周次、节次和原始来源等完整课表信息可展开查看。
- 课表传入所选日期，在完整目录内跨来源、跨原分页定位当天录播；当天多条全部展示供选择，不自动播放。无记录时明确说明并保留其他日期。
- 全来源记录按学校时区的授课时间倒序，再按日期分组并做展示层分页；同日同时间采用稳定的来源/记录次序，教师仅作来源标签。
- 缺少有效日期的条目单独列为日期未知，不猜测日期。同日不同来源不误去重，来源数量/空来源状态仍可查看。
- 重排仅改变展示，不丢失原学校课程、记录及分页定位；播放仍恢复准确来源，返回保留日期分组和滚动位置。

### U3：统一导入任务面板

- 设置和课表入口保留，明确当前学期及任务范围；主计数按同名课程集合，学校来源数与关联课表项数分开显示，避免把排课段数当课程门数。
- 区分待处理、进行中、完成、未匹配、失败、取消；每项可查看原因。未匹配不是网络失败，同名多教师不再要求选择其中一门。
- 提供只重试失败项、停止并保留成果、查看已导入课程。当前任务内复用完整来源；同名集合全部成功才替换旧目录。
- 失败重试仍重新核对学期、名称和当前目录，不能将过时来源混入新集合；取消/退出后的旧回调不能写回。
- 本阶段计划前台任务及已完成目录持久化；任务本身跨进程自动续传、后台任务不是默认交付项，需要时另行确认。

### U4、U6及R3呈现：录播提示与连接状态

- 课表对本地目录中已有录播的课程显示轻量图标；不为图标逐门联网，不把未检查显示为无录播。
- 在课程页区分有录播、成功读取但暂无、尚未检查；图标提供无障碍语义，窄列和大字优先保留课程名/地点，不能依赖颜色单独传达状态。
- 连接提示条分别展示本地目录、更新时间、更新中、需要登录、学校服务异常等；更新失败不遮挡可读旧列表。
- 官方认证成功或重试后回到原课程/任务/日期和列表位置，保留完整详情、单课刷新与直播未开放页签。

**验收与交付**

- 先以合成数据提供课程页、任务面板、提示条和课表图标草图；实质页面选择经用户确认后实施。
- 覆盖当天无记录/多记录、跨来源和原分页、同录播ID不同来源、日期未知、空来源、部分失败及取消，确认点击播放没有串来源。
- 小屏/大字/浅深色、横竖屏、安全区、触控及无障碍检查；从今日/周/日进入一致，返回恢复学期、周次和列表位置。
- 按日期列表、任务面板、课表提示分别作为独立交付提交，不积攒全部UI后才同步。

## 阶段S4：播放器交互与完整听课能力

**工作内容（U5、R6基础）**

- 保留默认PPT主画面、教师小窗、学生画面切换、独立关闭/恢复及单路禁用规则。
- 小窗支持有界拖动和调整大小，区分拖动/缩放与点按交换；不覆盖学校水印、系统安全区和关键操作。旋转、全屏和布局变化后位置仍合法。
- 全屏播放时控制栏自动隐藏，点按恢复；暂停、错误、拖动进度、菜单和无障碍操作期间保持可操作，退出全屏及返回路径可达。
- 新增前后跳转10秒，限制在有效时长内，所有已显示画面统一跳转。
- 本机断点只保存必要复合记录标识、进度和更新时间；按学期/课程来源隔离，退出学校会话时清理，避免账号切换复用旧进度。不存媒体地址和凭据。
- 续播前仍校验当前权限；新记录、无效时长、接近结尾及已结束记录有明确处理，不能自动恢复到结束态。
- 核对音频焦点、听感、完整课时双流同步、倍速/拖动/画面切换后的同步、来电、锁屏、前后台与旋转；继续遵守当前后台暂停边界。
- 学校水印按官方配置呈现。服务器观看记录作为独立协议核实项，明确本机进度不等于学校记录；未经核实与另行确认不实现上报，不隐藏官方播放器补记录。

**验收与交付**

- 组件与原生合成媒体检查覆盖手势边界、关闭恢复、自动隐藏、±10秒、断点读写/清理及生命周期，避免仅检查Flutter按钮存在。
- 本人授权样本按一节完整课时验证，记录环境、持续时长、操作及可观察结果；人工听音、长期同步、水印开启分别给出结果，缺少样本时保留未验证。
- 交互、本机断点、原生可靠性分项实现和提交；学校观看记录仍单列状态，不与本机续播混为完成。

## 阶段S5：会话与真实链路验收

- 按现有[长期会话测试](research/SESSION_LONGEVITY_TEST.md)继续实际跨天复测，区分WebVPN、教务与课堂；24小时、72小时和7天以自然时间为准，未采样节点如实记为未测，不补造过去结果。
- 现有B组T0为2026-11-11 12:41:13（UTC+8），相应检查点为11月12/14/18日12:41:13。继续记录期间访问、更新与重新认证；若发生重新登录则保留旧组结论并建立新基线。
- 扫码独立基线需本人完成；账号密码官方“记住”勾选/未勾选的结论分开记录。有前台访问的日常使用与完全闲置7天不是同一条件，已有A/B结果也不能严格归因于勾选项。
- 每次确实请求新课表、目录或当次媒体，排除离线目录和短时缓存；学校网络故障与认证失效分开记录。遇到网络故障可保留会话等待可达后复测，不能直接判会话过期。
- 完成S2的完整学期独立核验、S4的完整课时核验，以及另一台设备的认证→平台→导入→播放复测；直连与WebVPN按可用环境分别记载。
- 将必要的原生合成媒体冒烟及release压缩后解析检查纳入可重复质量检查，真实学校数据和登录不进入CI。

**验收与交付**

- 使用矩阵分别列出已实现、合成检查、模拟器、另一设备、真实学校及发布包结果，每项关联精确构建标识。
- 7天目标成功、提前失效、网络阻塞或缺少观察都有明确结论；结果不等于服务端永久免登录保证，也不自动授权自动重登。
- 本阶段可与其他阶段并行观察，但认证状态误分类修复前，不根据当前错误提示推断会话寿命。本轮只编写计划，不新建定时监测任务。

- 完善原生及release验证门槛时保留完整性检查和退出码；不以旧提交CI、debug包或单次播放代替发布提交验证。

**验收与交付**

- 从安装包界面能识别其源码与类型，文档能够追溯该包的验证范围。
- 新签名方案有可复核的升级/数据保留路径，密钥不进入仓库或日志；没有迁移证据前继续保留现有可升级方式。
- 发布属于后续单独授权动作，本计划完成不创建Release、不自动合并main、不触碰已发布标签和附件。

## 开发顺序与状态更新

建议顺序为：S0当前规则整理 → S1故障恢复 → S2数据保护 → S3课程页/日期列表 → S3导入面板/提示 → S4播放器 → S5收敛验收 → S6交付准备。控制器拆分随相关功能分步进行；S5自然跨天观察可并行，不为等待7天阻挡其他已授权工作。
