以下采样来自干净`d75f313`、正常对比度的合成今日页，严格按VM单调时钟窗口过滤，并对B/E事件成对统计；后续199f2a0仅修正提升对比度时的底栏降级，不把旧采样写成新源码重新测量。

| 今日页正常环境光 | 5.028秒 | 169 | 158 |
| 系统三项动画比例均为0，合成今日页稳定后 | 5.025秒 | 0 | 0 |

正常今日页Animator::BeginFrame中位0.495ms、P95 0.888ms；GPURasterizer::Draw中位16.909ms、P95 23.448ms、最大34.365ms，包含提交/等待等引擎耗时。它们**不是Flutter FrameTiming或手机帧率**；主机GPU转译、WHPX和其他宿主负载会影响结果，不能据此宣布60/120fps或功耗达标，也未凭模拟器波动改动已验收视觉。

切设置后仅见少量更新而非持续环境光绘制；后台首次采样包含16次进入后台的过渡事件，等待稳定后重采样为0，保留两次结果。一次早期减少动画采样处于空课表引导，未用作上表证据；上表减少动画样本已确认在合成今日页。采样后恢复原时间线流及精确端口转发；服务令牌未落盘。
