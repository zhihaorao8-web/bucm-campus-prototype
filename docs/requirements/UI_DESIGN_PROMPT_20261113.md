# 校园课表应用 UI/UX 前端设计规范与实现提示词

## 1. 角色与核心设计目标
你是一位精通现代移动端 UI/UX 设计与物理微交互的前端架构师。请为一个高校校园课表应用构建前端界面，包含「今日（Today）」、「课表（Schedule）」、「设置（Settings）」三个核心视图及详情抽屉交互。

**核心审美基调**：
- **高级感（Quiet Depth）**：拒绝冰冷的纯白与高饱和度色块堆砌。以温润的宣纸质感为底，结合克制的莫兰迪（Morandi）色彩体系与清晰的排版秩序。
- **灵动感（Fluid & Tactile）**：引入有机弥散极光背景、物理阻尼弹簧动效（Spring Physics）、时间轴实时流逝反馈以及扑克牌式层叠卡片交互。

## 2. 视觉系统与设计令牌（Design Tokens）

### 2.1 色彩与材质系统
- **全局宣纸底色**：`#FAF9F6`（暖调燕麦/宣纸白），全局叠加 `1.5%` 极细腻的 SVG 分形噪点纹理层（`pointer-events: none`），营造温润、耐看的阅读质感。
- **卡片与容器表层**：
  - 主容器底色：`#FFFFFF` 或 `rgba(255, 255, 255, 0.85)` 搭配微弱环境阴影 `0 4px 20px -2px rgba(28, 30, 33, 0.04)`。
  - 边框线：`1px solid rgba(28, 30, 33, 0.06)`。
- **文本层级**：
  - 主标题/核心信息：`#1E2022`（深炭灰，字重 `600`~`700`）。
  - 次要信息/地点/教师：`#5C6168`。
  - 弱化说明/时间戳：`#8A8E96`。
- **克制的学科莫兰迪色系（双模式支持）**：
  - 蓝（基础课）：主色 `#3B6EF6` / 极浅底 `#F2F6FF`
  - 棕（专业课）：主色 `#9A6B2F` / 极浅底 `#FAF5EE`
  - 绿（实验课）：主色 `#257A54` / 极浅底 `#EFF8F3`
  - 紫（选修课）：主色 `#6E44B8` / 极浅底 `#F5F0FC`
  - 珊瑚红（重点/冲突提示）：主色 `#C23B3B` / 极浅底 `#FDF1F1`
  - *卡片风格规范*：默认采用「纯白底色 + 左侧 `3px` 高饱和度圆角指示色条」的极简高级风，同时兼容「柔和莫兰迪全底填充」模式。

### 2.2 排版与数字规范
- **字体族**：优先使用系统无衬线字体（`-apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans SC", sans-serif`）。
- **等宽数字（Tabular Figures）**：所有大号时间、节次时间、倒计时及日期数字必须强制启用 `font-variant-numeric: tabular-nums`，确保动态时间变化时数字不发生横向抖动。

### 2.3 左上角有机弥散极光流光（Ambient Mesh Aurora）
- **位置与结构**：置于页面左上角主标题区域背后，由 3 个低饱和度渐变光晕球体（Blob）构成，叠加 `filter: blur(38px)` 高斯模糊与 `10s~14s` 缓动呼吸漂浮关键帧动画（`ease-in-out infinite alternate`）。
- **跨视图主题色无缝过渡（`transition: background 0.9s ease`）**：
  - **「今日」视图**：晨曦暖杏（`rgba(255, 198, 130, 0.35)`）+ 晴空天青（`rgba(120, 185, 255, 0.30)`），呼应太阳图标与时间流逝。
  - **「课表」视图**：学院钴蓝（`rgba(96, 150, 253, 0.32)`）+ 薄荷青绿（`rgba(110, 215, 180, 0.28)`），呼应专注与秩序。
  - **「设置」视图**：微醺暮紫（`rgba(168, 130, 245, 0.30)`）+ 柔雾暖金（`rgba(245, 195, 145, 0.28)`），呼应个性化定制。

## 3. 核心视图与组件规范

### 3.1 「今日（Today）」视图：此刻专注仪表盘
1. **顶栏区域**：左上角大标题 `今日`（`32px` Bold），下方展示完整日期（如 `11月13日，星期五`）与当前教学周徽章；右上角提供轻量操作入口（如切换示例模式/时间模拟控制台）。
2. **「正在上课」Hero 焦点卡片**：
   - 顶部状态行：左侧为带**呼吸灯扩散光环动效**的绿色/蓝色圆点 + `正在上课`；右侧为圆角胶囊倒计时标签（如 `剩 24 min`）。
   - 核心视觉锚点：超大号等宽开始时间（如 `13:30`，`42px` Bold 主题蓝），紧跟下课时间提示（`15:00 下课`）。
   - 底部课堂进度条：圆角细轨道（高度 `4px`），实时显示当前课程已完成百分比，并伴随平滑宽度过渡动画。
3. **「今天的安排」连接式垂直时间轴**：
   - 左侧贯穿一条 `1.5px` 垂直时间轴线，节点圆点随课程状态变化：
     - **已结束课程**：节点显示完成对勾，整张卡片自动降低不透明度（`opacity: 0.52`），形成视觉退让。
     - **进行中课程**：节点高亮发光，卡片保持 `100%` 清晰度并带微弱边框高亮。
     - **未开始课程**：节点为空心圆环，卡片保持纯净白底。
   - 课间/午休间隔：在时间轴中间嵌入轻盈虚线与居中文字（如 `午休 · 12:00 - 13:30`），自然划分全天节奏。

### 3.2 「课表（Schedule）」视图：秩序网格与冲突层叠
1. **精简顶栏与周/日双模式**：
   - 将学期选择收敛至标题旁下拉触发器；右上角置入 **iOS 风格滑动分段控制器（Segmented Control）**，在「周」与「日」视图间以弹簧滑块无缝切换。
   - **周次导航栏**：左右箭头支持点击与触控横向滑动手势切换周次，周数数字切换时呈现**纵向翻牌动效**；当浏览非当前周时，右侧以物理弹跳动效浮现蓝色 `本周` 快捷回弹胶囊。
2. **周视图网格（Week Grid）**：
   - 顶部星期栏高亮「今日」列（日期数字置于蓝色实心小圆圈内）。
   - 午休与晚休采用极细居中虚线分隔，不破坏整体呼吸感。
3. **重塑「冲突课程」的层叠卡片交互（核心痛点解决）**：
   - 当同一节次存在多门冲突课程时，**禁止并排挤压导致文字截断**。
   - 采用**扑克牌层叠形态（Stacked Cards）**：主课卡片保持完整网格宽度与清晰排版；底层露出一张微向右下偏移的副卡边缘，右上角叠加精致的 `+1 冲突` 徽章。
   - 点击层叠卡片后，底部弹簧抽屉展开并列展示两门课程详情，并提供**「设为优先显示」**按钮，支持一键互换网格中的主副显示顺序。
4. **日视图精览（Day View）**：
   - 切换至「日」视图或点击任意星期表头，展示单日大卡片时间流，每张卡片内置独立课前提醒开关与课堂备注摘要。

### 3.3 「设置（Settings）」视图：质感控制台
- 采用分组圆角白底卡片列表（Grouped Inset List），提供实时生效的个性化开关：
  - 教务系统数据同步卡片（带旋转刷新动效与上次同步时间）。
  - **视觉质感控制台**：支持一键开关「左上角极光流光」、「宣纸微噪点纹理」、切换「卡片着色风格（极简色条 / 柔和全底）」及「显示周末列」。

## 4. 导航与物理微交互规范（Micro-interactions）

1. **底部悬浮玻璃胶囊导航栏（Floating Glass Dock）**：
   - 悬浮于屏幕底部（距底 `20px`），采用大圆角胶囊造型（`border-radius: 999px`）。
   - 材质：`background: rgba(242, 242, 244, 0.78)`，`backdrop-filter: blur(22px) saturate(180%)`，外加一圈 `1px solid rgba(255, 255, 255, 0.7)` 高光描边与柔和投影。
   - **流体高亮滑块**：包含「今日」、「课表」、「设置」三个 Tab，切换时选中态的灰色椭圆滑块使用阻尼弹簧曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)` 横向平滑滑动，图标与文字同步切换为主题蓝。
2. **触控按压与详情抽屉（Bottom Sheet）**：
   - 所有课程卡片具备按压缩放反馈（`:active { transform: scale(0.975); transition: transform 0.15s ease; }`）。
   - 点击卡片后，背景遮罩渐显高斯模糊，底部详情抽屉以弹簧曲线向上滑出，顶部带抓手横条（Drag Handle），完整展示课程名称、教师、教学楼教室、周次范围、节次时间及快捷操作按钮。

## 5. 技术实现约束
- 使用单文件响应式移动端容器（最大宽度 `430px` 居中展示，适配手机视口高度 `100dvh`），无需外部重型 UI 框架，通过原生语义化 HTML5、现代 CSS 变量/Grid/Flexbox 与模块化 JavaScript 实现完整的状态管理与交互闭环。
